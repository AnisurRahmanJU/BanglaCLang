# বাংলা সি ভাষা
## বাংলা কোড
### ```সিনটেক্স```
```py
# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_ইন_আউট.হেডার >
পূর্ণ মৌলিক()
{
   দেখাও("ওহে বিশ্ব\n");
   ফেরত ০;
}
```
- ```# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_ইন_আউট.হেডার >``` হচ্ছে C language এ হেডার ফাইল.```#include<stdio.h>```
- ```পূর্ণ``` হলো ```int```
- ```মৌলিক()``` হচ্ছে ```main()``` ফাংশন।
- ```দেখাও()``` হচ্ছে ```printf()``` ফাংশন।
- ```ফেরত ০``` হচ্ছে ```return 0```
