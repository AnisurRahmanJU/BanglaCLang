# বাংলা সি ভাষা
## বাংলা কোড
```সিনটেক্স```
```py
# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_ইন_আউট.হেডার >
পূর্ণ মৌলিক()
{
   দেখাও("ওহে বিশ্ব\n");
   ফেরত ০;
}
```
- ```# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_ইন_আউট.হেডার >``` হচ্ছে C language এ হেডার ফাইল.```#include<stdio.h>```
- ```পূর্ণ``` হলো ```int```
- ```মৌলিক()``` হচ্ছে ```main()``` ফাংশন।
- ```দেখাও()``` হচ্ছে ```printf()``` ফাংশন।
- ```ফেরত ০``` হচ্ছে ```return 0```
  

```ইনপুট ও আউটপুট:```
```py
# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_ইন_আউট.হেডার >
পূর্ণ মৌলিক()
{
   পূর্ণ নাম্বার;
   দেখাও ("একটি সংখ্যা নিই:");
   নাও("%প", &নাম্বার);
   দেখাও("%প\n", নাম্বার);
   ফেরত ০;
}
```
```ফরমেট স্ট্রিং:```
```py
# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_ইন_আউট.হেডার >
# অন্তর্ভুক্ত < স্ট্যান্ডার্ড_লাইব্রেরি.হেডার >
# অন্তর্ভুক্ত < স্ট্রিং.হেডার >
# অন্তর্ভুক্ত < গণিত.হেডার >
 
পূর্ণ মৌলিক()
{
   পূর্ণ নাম্বার = ১০০;
   দশম সিজিপিএ = ৫.০০;
   বর্ণ ইংরেজি = 'A';
   ডাবল হিসাব = ১২৩৪৫.৬৭৮৯০;
   বর্ণ অ্যারে[১০০]="মোঃ আনিছুর রহমান";
    
   দেখাও("%প\n", নাম্বার);
   দেখাও("%দ\n", সিজিপিএ);
   দেখাও("%ব\n", ইংরেজি);
   দেখাও("%লদ\n", হিসাব);
   দেখাও("%স\n", অ্যারে);
    
   ফেরত ০;
}
```
